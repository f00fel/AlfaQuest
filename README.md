# Альфа Квест

Офисная AR-игра для iOS 16+ на SwiftUI и ARKit. Игроки сканируют постеры с котиками, ищут монеты и выполняют ежедневные задания. Профиль и прогресс пока хранятся на устройстве.

## Запуск

1. Открыть `AlfaQuest.xcodeproj` в Xcode.
2. В настройках таргета `AlfaQuest` перейти в **Signing & Capabilities** и выбрать свою команду в поле **Team**. Apple Account добавляется через **Xcode → Settings → Apple Accounts**.
3. Подключить iPhone, выбрать его в списке устройств и запустить приложение через **⌘R**.

Для AR нужен физический iPhone с поддержкой ARKit. В симуляторе можно проверить интерфейс и игровую логику.

Предпросмотр интерфейса: `AlfaQuest/App/RootView.swift` → **Editor → Canvas**. Данные предпросмотра хранятся отдельно от профиля приложения.

## Как играть

1. Создать профиль и нажать «Я в офисе». Отметка даёт две внутренние монеты раз в день.
2. Открыть камеру во время одной из волн: **10:00–12:00**, **13:00–15:00** или **16:00–18:00**. Время считается по часовому поясу устройства.
3. Найти постер с котиком и навести на него камеру. В каждой волне доступны три личных объекта в разных зонах.
4. Повернуть телефон и найти появившийся объект рядом. На поиск и сбор есть **25 секунд**, на каждый объект — три попытки. Закрытие камеры тоже расходует попытку.
5. Нажать на находку. Награда начисляется один раз, баланс и задания обновляются после сбора.

Объект появляется случайно слева или справа, примерно в метре от игрока, и остаётся в выбранной точке. Камеру можно открывать и между волнами, но новых объектов в это время нет.

Внутренние монеты красные, внешние зелёные, супер-монеты золотые. Предмет коллекции выглядит как фиолетовый кристалл. Супер-монеты из обычных находок не выпадают.

[Постеры для печати](Docs/OfficeMarkers.pdf) — восемь страниц A5. Печатать в масштабе 100%, без обрезки фона. Ширина цветной картинки должна быть 12 см: этот размер используется при распознавании.

## Структура проекта

| Папка | Что внутри |
| --- | --- |
| `AlfaQuest/Core` | Игровые правила, волны, награды, задания и состояние игрока. |
| `AlfaQuest/Storage` | Сохранение прогресса, проверка данных и перенос старого профиля. |
| `AlfaQuest/App` | Состояние приложения и навигация. |
| `AlfaQuest/Features` | Главная, ежедневные задания и профиль. |
| `AlfaQuest/Camera` | AR-сессия, распознавание постеров, размещение и сбор объектов, звук и вибрация. |
| `AlfaQuest/Design` | Общие компоненты интерфейса, цвета и значки валют. |
| `Tests` | Проверки игровой логики, сохранений и работы камеры без запуска AR. |

Внешних библиотек нет. Игровые ограничения находятся в `GameRules`, модели монет — в `CoinNodeFactory`, расчёт позиции находок — в `HuntObjectPlacement`. Стиль Swift-кода задан в `.swift-format`; предупреждения компилятора считаются ошибками.

## Проверки

Запуск из каталога `iOS/AlfaQuest`:

```sh
./scripts/check.sh
```

Если вместо Xcode выбраны Command Line Tools, можно указать путь к Xcode для запуска скрипта:

```sh
DEVELOPER_DIR="/Applications/Xcode.app/Contents/Developer" ./scripts/check.sh
```

Путь в примере нужно заменить, если Xcode установлен в другой папке.

Скрипт проверяет расписание волн, награды и лимиты, повторный сбор, таймер, попытки, задания, сохранения и размещение объектов. Отдельные сценарии проверяют запуск камеры, уход в фон и восстановление после прерывания.

Распознавание постеров и удобство поиска нужно проверять на iPhone: скрипт не запускает настоящую AR-сессию.

## Диагностика AR

При сбое камера показывает описание ошибки, её домен и код. Последние 60 событий записываются в `Library/Logs/ARCamera/diagnostics.json` внутри контейнера приложения: запуск сессии, проверка постеров, изменения трекинга и ошибки. Кадры камеры и координаты в журнал не попадают.

## Что ещё не подключено

Сервер, регистрация по ключам, авторизация, роли, проверка присутствия в офисе, знакомства по QR/BLE, магазин и аналитика руководителя. Отметка в офисе и начисление наград пока работают локально. Перед общим запуском их нужно перенести на сервер: локальные данные и время устройства можно изменить.

Постеры взяты из PDF макета, размер картинок — 173×173 пикселя. Для чёткой печати нужны исходные изображения в большем разрешении. Модели монет создаются кодом по видеореференсам; готовые модели Blender в проект не импортированы.
