# Альфа Квест

Нативный iOS-прототип на SwiftUI и ARKit, iOS 16+. Основа — аналитика и материалы из [папки проекта](https://drive.google.com/drive/folders/1XS7yLBBt6Y3WoucrSqxrNPau4EtfkU15), обновлённые 5 ноября 2026.

## Запуск

Открой `AlfaQuest.xcodeproj`, выбери свой iPhone и нажми Run. Подпись Personal Team уже настроена для текущего проекта; на другом Mac выбери свою Team в Signing & Capabilities. На симуляторе работают экраны и игровой код, камера AR требует физического iPhone.

Для Canvas открой `AlfaQuest/App/RootView.swift` и включи Editor → Canvas. Предпросмотр использует отдельное сохранение, которое не затрагивает профиль приложения.

## Рабочий цикл

1. Создай локальный профиль и нажми «Я в офисе»: +2 внутренние монеты раз в день.
2. Во время волн 10:00–12:00, 13:00–15:00 и 16:00–18:00 открой камеру.
3. Наведи её на одного из восьми котиков. В каждой волне у игрока три объекта в разных зонах.
4. Поверни телефон и найди объект рядом: он появляется слева или справа за пределами начального кадра, на расстоянии 0,9–1,3 м и остаётся в выбранной точке пространства. На поиск и сбор есть 25 секунд. На объект доступно три попытки; закрытие камеры не возвращает потраченную попытку.
5. Баланс, очки и ежедневные задания обновятся после сохранения. Повторный сбор не начисляет награду.

Камеру можно открыть и вне волны: расписание ограничивает появление объектов, а не видеопоток.

[Постеры для печати](Docs/OfficeMarkers.pdf): восемь страниц A5, печатать в масштабе 100%. Ширина цветной картинки должна быть 12 см. Не обрезай фон: AR-каталог использует картинку целиком.

Внутренние монеты красные, внешние зелёные, супер-монеты золотые. На монетах — компас из видео. Предмет коллекции показан фиолетовым кристаллом. Супер-монеты из обычных находок не выпадают.

## Код

| Папка | Ответственность |
| --- | --- |
| `AlfaQuest/Core` | Волны, персональные объекты, попытки, награды, задания, серия и состояние игрока. Только Foundation. |
| `AlfaQuest/Storage` | Версия сохранения, миграция старого профиля и проверка данных. |
| `AlfaQuest/App` | Состояние приложения, навигация и применение изменений после сохранения. |
| `AlfaQuest/Features` | Главная, ежедневные задания и профиль. |
| `AlfaQuest/Camera` | Разрешение камеры, AR-сессия, распознавание постеров, геометрия монет и обратная связь. |
| `AlfaQuest/Design` | Цвета, общие компоненты и значки валют. |
| `Tests` | Проверки бизнес-правил, сохранений, размещения находок и переходов состояния камеры без запуска AR. |

Внешних библиотек нет. `AppStore` работает на MainActor; AR-события передают на него значения. Размеры и материалы монет находятся в `CoinNodeFactory`, игровые ограничения — в `GameRules`. В проекте включены строгая проверка конкурентного доступа и предупреждения Swift как ошибки. Форматирование задаёт `.swift-format`.

## Проверки

Из этой папки:

```sh
./scripts/check.sh
```

Если системные инструменты смотрят на Command Line Tools, для текущего Mac:

```sh
DEVELOPER_DIR=/Users/mac/Downloads/Xcode.app/Contents/Developer ./scripts/check.sh
```

Проверяются границы волн, стабильность персональных объектов, веса наград, повторные касания, таймер, три попытки, дневные награды, недельный лимит внешних находок, серия, восстановление и миграция профиля. Проверки камеры покрывают повторный запрос запуска, уход в фон, закрытие во время подготовки, восстановление после прерывания и запоздавшие ошибки старой сессии. Старая запись профиля остаётся в хранилище; при повреждённом сохранении приложение предлагает восстановление и не затирает его автоматически. Старый демобаланс переносится с ограничением внутренних монет до 100; суммарное число прежних находок сохраняется.

Проверка 12 ноября 2026: 27 сценариев, строгий Swift lint, сборка Debug для симулятора и подписанная Release для iPhone прошли. Версия 0.3.1 установлена и запущена на iPhone 12 Pro. После установки пользователь подтвердил работу камеры и появление монет при распознавании котиков. Три вида монет дополнительно проверены в отдельном рендере SceneKit.

Проверка 16 ноября 2026, версия 0.3.2: 30 сценариев и строгий Swift lint прошли, Release для iOS собрана без подписи. Проверены сбор после прежних 10 секунд и перед новым пределом 25 секунд, размещение по обе стороны от игрока и сохранение высоты при наклоне телефона. Угол появления — 55–95° влево или вправо; расстояние — 0,9–1,3 м. Новая позиция выбирается один раз на попытку. Установка 0.3.2 и проверка поиска на телефоне не выполнены: устройство недоступно, Xcode сообщает об отсутствии Apple Account и профиля подписи.

В 0.3.1 запуск AR проходит через `CameraSessionLifecycle`: одновременно подготавливается один запуск, события предыдущего запуска игнорируются. После ошибки, прерывания или возвращения из фона создаётся новая `ARSession`. Изображения постеров подготавливаются и проверяются ARKit на устройстве до запуска камеры. Ошибка показывает свой домен и код; переход в настройки предлагается только при фактическом отказе в разрешении камеры.

Последние 60 диагностических событий сохраняются в `Library/Logs/ARCamera/diagnostics.json` внутри контейнера приложения. В журнал входят запуск, проверка постеров, состояния трекинга и ошибки; изображения камеры и координаты не сохраняются. Это позволяет отличить проблему разрешения от ошибки конфигурации или видеозахвата.

## Границы прототипа

Регистрация по ключам, JWT, роли, серверное начисление наград, геопроверка отметки, знакомства по QR/BLE, магазин и аналитика руководителя требуют API и конфигурации геозоны. Их адресов в переданных материалах нет. Сейчас профиль, отметка и экономика локальные: они подходят для проверки игрового цикла, но не обеспечивают серверную защиту от подмены времени или изменения данных.

Постеры извлечены из PDF-снимка макета: исходные картинки имеют размер 173×173 пикселя. Для проверки печати и распознавания нужны реальные iPhone и освещение; для итоговых постеров лучше использовать исходники Figma в большем разрешении. В папке есть видео Blender, но нет самих `.blend`/`.usdz`: модели воспроизведены процедурной геометрией, а не импортированы из видео.
